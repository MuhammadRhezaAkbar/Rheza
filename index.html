Apa Itu Cloud Computing?

Cloud computing adalah model penyediaan sumber daya komputasi melalui jaringan sesuai kebutuhan pengguna.

Manfaat Cloud Computing

  • Akses layanan melalui jaringan.
  • Kapasitas sumber daya dapat disesuaikan.
  • Mendukung penyimpanan dan penyediaan aplikasi.
